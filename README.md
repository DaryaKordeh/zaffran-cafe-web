
# ☕ Zaffran Cafe (قهوه‌خانهٔ زعفران)

A responsive, single-page HTML/CSS website for a traditional Persian coffee house. The design features a warm, elegant aesthetic inspired by saffron, espresso, and vintage coffee culture.

## ✨ Features

- **Responsive layout** – adapts to desktop, tablet, and mobile screens

- **Persian (RTL) support** – full right-to-left layout with `Vazirmatn` and `Playfair Display` fonts

- **Hero section** – animated steam effect and fade-up entrance animations

- **Menu display** – coffee and sweets categories with product cards

- **Photo gallery** – grid layout with hover captions

- **Testimonials marquee** – auto-scrolling customer reviews (pauses on hover)

- **Newsletter subscription** – call-to-action section with input field

- **Sticky header** – navigation bar with hover underline effects

- **Animated seal logo** – rotating SVG emblem

- **CSS custom properties** – consistent theming via `:root` variables

- **Accessibility** – uses `aria-label`, prefers-reduced-motion

> **Note:** All image references point to `/photo/darya--img1.jpeg`. Replace these with your own images for a complete experience.

## 🚀 How to Use

1. Open `zaffran-cafe.html` in any modern browser

2. All styles are embedded via the linked `style.css`

3. Fonts are loaded from Google Fonts (Vazirmatn + Playfair Display)

4. No build tools or server required – works as a static page

## 🖥️ Browser Support

- Modern Chrome, Firefox, Safari, Edge

- Uses CSS Grid, Flexbox, custom properties, and `@keyframes` animations

- Graceful fallback for reduced-motion preferences

## 📝 Customization Ideas

- Replace all `darya--img1.jpeg` placeholders with actual café photography

- Update menu items, prices, and descriptions in the `.cards` sections

- Modify the testimonial text and names in the marquee

- Adjust the subscription email input to connect with a backend form handler

- Change the SVG text in the seal logo (currently "قهوه‌خانهٔ زعفران ✦ از ۱۳۹۸ ✦")
